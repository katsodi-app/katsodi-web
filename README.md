# Katsodi

> Русский · [[README.en|English]]

Браузерное пространство для совместных вечеров. Версия 0.4 — фирменный интерфейс всех известных экранов и подготовленная серверная основа; полноценный многопользовательский MVP ещё не принят.

## Запуск

Node.js >=20.9 (для нового окружения используйте Node 22). pnpm 12.16.1.

```sh
npm exec --yes --package=pnpm@12.16.1 -- pnpm install
npm run dev
```

Открыть http://127.0.0.1:3000. При установленном pnpm можно использовать pnpm install / pnpm dev.

Добавлены пять тем, редакционное слайдшоу, локальные шрифты и настоящие обложки фандомов. Реализованы RU/EN, каталог, локальные комнаты, сохранённое, 150 фандомов, безопасная проверка ссылок. Supabase подключён, пользователь получил стандартное письмо; полная приёмка аккаунтов и серверных комнат ещё впереди — [[docs/Backend Setup]]. Новый дизайн комнаты — [[docs/Features/Room Experience]]. Для стикеров и сжатых картинок подготовлена отдельная миграция — [[docs/Features/Chat Media]]; в облаке она не выполнялась. Realtime, голос и синхронизация не подключены. Без env доступен локальный прототип.

Откройте корень репозитория как Obsidian vault.

Карта всех экранов и их реальных возможностей — [[docs/Page Catalogue]]. Дизайн друзей и глобальной модерации подготовлен, эти сервисы пока не подключены.

# Официальные ссылки фандомов

> Русский · [[docs/en/Features/Official Fandom Links|English]]

## Зачем нужна
Показать на странице фандома, где его смотреть, слушать или читать официально, в дополнение к уже существующей ссылке «Где посмотреть».

## Пользователи и роли
Все посетители страницы фандома. Администратор и пользователи ссылки не редактируют; список собирается скриптом.

## Пользовательские сценарии
Открыть /fandoms/cinema-15 и увидеть блок «Официально»: Max для «Дома Дракона». Для аниме — поиск в Crunchyroll, для групп — официальный YouTube-канал, для спорта — трансляции лиги или федерации.

## Правила поведения
Существующие ссылки (fandom-watch-links.json) не меняются. Показываются только ссылки, прошедшие проверку: ответ 200 и название страницы, совпадающее с ожидаемым. Ссылки, которые не удалось проверить (гео-блок, 404, защита от ботов), не показываются; фандом без проверенной ссылки блок не получает. Защиту от ботов мы не обходим.

## Интерфейс и состояния
Карточки с сервисом, типом («Стриминг», «Официальный сайт», «Канал», «Трансляции», «Поиск в сервисе») и датой проверки; подпись о том, что доступность и подписка зависят от региона. Открываются в новой вкладке с rel="noopener noreferrer". RU/EN.

## Техническая реализация
- scripts/official-links-candidates.json — кандидаты {provider, url, kind, expect}.
- scripts/check-official-links.mjs — загружает каждую страницу, сравнивает title/og:title/название YouTube-канала с expect; с --write пишет src/data/fandom-official-links.json с датой checked.
- Страницы сериалов Crunchyroll закрыты проверкой Cloudflare, поэтому для них используется официальный поиск crunchyroll.com/search?q=…; для такого вида (kind: search) проверяется только форма адреса.
- FandomConnections выводит блок .fandom-official.

## Данные и доступы
Статический JSON в сборке, без базы данных и без запросов из браузера.

## Безопасность и приватность
Только https-ссылки на официальные домены; никаких данных пользователя в адресах.

## Критерии приёмки
- Проверка 06.11.2026: 133 из 133 ссылок, 131 фандом.
- tests/unit/official-links.test.ts: id из каталога, https, известный тип, дата, только официальный поиск, без повторов.
- e2e fandom-connections: блок «Официально» на странице Dune, старая ссылка на месте; axe на странице фандома в обеих темах.

## Ограничения и следующие шаги
У 19 фандомов нет проверенной ссылки (например «Сверхъестественное», «Секретные материалы», Nintendo, Peacock). Ссылки устаревают: перед релизом снова запускать `node scripts/check-official-links.mjs --write`. Каталог и источники: [[docs/Features/Fandom Detail]], [[docs/Fandom Sources]].

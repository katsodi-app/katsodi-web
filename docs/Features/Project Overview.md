# Презентация проекта и восстановление аватарок

> Русский · [[docs/en/Features/Project Overview|English]]

## Зачем нужна
Представить Katsodi на `/overview`, восстановить выбранные владельцем прежние аватарки фандомов и составить список оставшихся вопросов приватности.

## Пользователи и роли
Страница доступна без аккаунта. Посетитель может перейти к созданию общей комнаты, музыке, фандомам или сообществам. Права API и ролей не меняются.

## Пользовательские сценарии
- Презентация: идея проекта, видео, музыка, фандомы, чат, голос, демонстрации, модерация, три шага начала и текущие ограничения.
- В обычном и компактном подвале — `/overview`, Discord `https://discord.gg/hDpZq49wCU` и Telegram `https://t.me/katsodi`.
- По явному последующему запросу владельца исходные аватарки, миниатюры, манифесты и палитры восстановлены из `bf3a46f`, до замены 98 изображений. Временная подборка стоковых фотографий и абстрактные обложки удалены.

## Правила поведения
Восстановление изображений не подтверждает права на публикацию. Исходные метаданные с пометками Fair use и неустановленного разрешения сохранены; остаётся замечание R1 из внутреннего юридического аудита. Неофициальные ссылки и парсеры Re:ANIME/LiveBall не возвращаются.

## Интерфейс и состояния
Последующее обновление: `OverviewFooter` используется на всех страницах через `SiteFooter`, включая вход/регистрацию. Контейнерные запросы перестраивают колонки по ширине самого футера. Ссылки на блоки презентации ведут на `/overview#…`, правовая навигация содержит все семь документов. Карточки героя вращаются между −5° и +5° вместе с плаванием; reduced-motion отключает движение. `OverviewFilm` синхронизирует большую центральную кнопку play/pause с нативным плеером, завершением и ошибками, поддерживает клавиатуру. Постер взят на 0.1s ролика Katsodi (после отдельного кадра-обложки, встроенного в MP4); сам ролик не перекодируется.
На страницу добавлен локальный 20-секундный ролик `/media/katsodi-launch.mp4` с постером, нативными кнопками, `playsInline`, `preload=none` и без автозапуска. Рядом доступна атрибуция музыки/изображений. Новый `OverviewMotion` добавляет появления при прокрутке, небольшую последовательную задержку элементов, движение карточек вслед за указателем и hover-реакции. Текст всегда доступен без JavaScript; reduced-motion отключает эффекты и отменяет активные появления при смене настройки. Наблюдатели и анимации очищаются при уходе со страницы. Референс движения — предоставленная запись страницы Claude; видеозапись референса не публикуется.
Обновление 11.11.2026: `/overview` использует отдельный `OverviewLayout` без сайдбара приложения: липкая шапка, центральный герой с восемью декоративными карточками, три переключаемых сценария, два блока возможностей, радиальная карта и большой многоколоночный подвал. Поиск в подвале отправляет настоящий GET-запрос в каталог фандомов. Мобильное меню раскрывается; вкладки поддерживают стрелки/Home/End; декоративная анимация учитывает reduced-motion. На узком экране карта превращается в сетку. Референсы — [Liner](https://tryliner.fun/) и [Claude overview](https://claude.com/product/overview); фотографии и рисунки — собственные существующие ресурсы Katsodi, сторонние логотипы и тексты не копируются.

Адаптивная RU/EN-презентация использует токены текущей темы, существующие редакционные фотографии и доступные ссылки. Она прямо сообщает о разработке, зависимости воспроизведения от сервиса и поддержке голоса/показа в совместимых настольных браузерах. Локальные черновики не называются общими комнатами; фиктивных пользователей и статистики нет. `/credits` сохраняет авторов, источники и исходные пометки прав на аватарки.

## Техническая реализация
- `src/components/overview-chrome.tsx`, `src/components/overview-screen.tsx`, `src/app/overview/page.tsx`, `src/app/overview.css`; все новые короткие строки RU/EN в `src/lib/i18n.ts`.
- `fandom-posters.json`, `curated-posters.json`, `editorial.ts`, `room-palettes.json` и файлы `public/images/fandoms` восстановлены из исходной версии. Регрессионная проверка сравнивает эффективные 150 изображений, авторов и пометки прав с сохранённым снимком аудита.
- Экспериментальные файлы фотографий, их манифест и скрипт подготовки удалены. Генератор прежних абстрактных обложек и их 294 публичных файла также удалены. История Git не переписывается.

## Данные и доступы
Минимальный возраст — 16 лет, Условия и Политика версии 0.4. По просьбе владельца публичная политика описывает текущие функции без имени оператора и блоков с непредоставленными сведениями. Поле `descriptionOnly` скрывает требование заполнения и дату действия только у этого документа; оно не объявляет документ юридически завершённым. С 12.11.2026 имя оператора и незаполненные сведения убраны из всех документов (см. [[docs/Features/Legal Pages]]).

## Безопасность и приватность
Исправление гидратации: параллакс и его cleanup не записывают inline `style` в элементы потоковой страницы из эффекта оболочки. Web Animations API сохраняет DOM-атрибуты React нетронутыми, отменяя эффект при уходе указателя, смене reduced-motion и размонтировании. `suppressHydrationWarning` не добавляется. Регрессия проверяет консоль гидратации, отсутствие изменённого style, повторное открытие страницы и переключение языка, включая dev/StrictMode.
В обоих языках установлен порог 16+, устаревшие пояснения о регистрации с 12 лет удалены. Проверка даты рождения не реализована. Удаление сведений из публичной политики не отменяет применимых требований раскрытия информации. Нерешённые вопросы остаются во внутренней заметке [[docs/Privacy Policy Checklist]].

## Редизайн 12.11.2026

Страница /overview пересобрана в атмосферной тёмной стилистике, цвета Katsodi сохранены:

- **Первый экран.** Полноэкранное ночное небо, бейдж «Open source», заголовок с одним рукописным словом («Смотрим *вместе*.») и стеклянное превью комнаты: плеер, чат, голос.
- **Шрифты.** Плакатная строка «Смотри · Слушай · Будь рядом» набрана сжатым Oswald, рукописные слова — Caveat. Оба шрифта под OFL, с кириллицей, подключаются через `next/font` только на этой странице и раздаются с собственного домена.
- **Разделы.** Шесть возможностей, три сценария (видео, музыка, фандомы), ролик, три шага, раздел «Сделано открыто» со ссылками на GitHub и пометкой о лицензии MIT, честный статус проекта и финальный плакат.
- **Кнопки.** Только два вида: «светлая» (#f5f5f5) и контурная; карточки плоские, с тонкой рамкой.
- **Анимации.** Появление при прокрутке, параллакс неба, плакатная строка движется вместе с прокруткой, стеклянное превью наклоняется за курсором, верхняя панель становится сплошной после первого экрана. Всё сделано через Web Animations API без изменения атрибутов, поэтому гидратация не ломается. При «уменьшении движения» анимации отключаются.
- **Футер.** Общий футер сайта (`src/components/site-footer.tsx`, `src/app/site-footer.css`) переписан: плоский, выровнен по краям контента, со ссылкой на GitHub и пометкой «Открытый код · MIT», компактный на телефоне. Он же показывается на /overview.
- **Тесты.** Проверки — `tests/e2e/overview.spec.ts`: гидратация, ролик, уменьшение движения, вкладки с клавиатуры, оба языка, мобильное меню, ширина 320 px, axe в двух темах и футер на разных страницах.

## Ограничения и следующие шаги
Права на 98 ранее отмеченных изображений остаются неустановленными. Нужны фактический хостинг, сроки хранения, достаточная идентификация оператора, действующие процедуры и решение о работе с детьми. Публичное размещение и отправки в сообщества не выполнялись.

# Страница фандома

> Русский · [[docs/en/Features/Fandom Detail|English]]

## Зачем нужна
Дать каждому миру из каталога собственную узнаваемую страницу.

## Пользователи и роли
Гость и авторизованный пользователь; выбор в каталоге пока локальный.

## Пользовательские сценарии
Нажать постер или название карточки, увидеть крупный постер, выбрать/снять выбор и перейти к созданию общей комнаты. Ниже — четыре других фандома той же категории.

## Правила поведения
Маршрут /fandoms/[slug] принимает существующий стабильный ID из каталога (например cinema-6). Неизвестный ID — 404. Нет выдуманных подписчиков, активности или комнат, якобы автоматически связанных с фандомом.

## Интерфейс и состояния
Обложка 3:4, название, категория, кнопка выбора, пояснение «в этом браузере», тематические карточки. Mobile собирает композицию вертикально. RU/EN; название произведения не переводится произвольно.

## Техническая реализация
FandomDetail использует fandoms/fandomAssets и существующий WorkspaceProvider.toggleFandom. FandomCard получает обычную ссылку на detail. Сохранение выбора проверяется после reload.

## Данные и доступы
Локальный выбор не подменяет серверные интересы профиля. Связь rooms.fandom_id добавляет отдельная миграция без изменения доступа к приватным комнатам.

## Безопасность и приватность
В URL попадают только ID известного каталога; произвольные внешние ссылки в обложки не вставляются.

## Критерии приёмки
Страница Dune, persist выбора, 404 неизвестного ID, desktop/mobile без переполнения.

## Ограничения и следующие шаги
Подбор публичных комнат реализован; для облачной базы нужна новая миграция. Краткие RU/EN справки, источники и конкретные внешние ссылки добавлены. Детали — [[docs/Features/Fandom Rooms]] и [[docs/Fandom Sources]].

# Активность в Discord

> Русский · [[docs/en/Features/Native Discord Activity|English]]

## Зачем нужна
Друзья в Discord видят, что человек сейчас смотрит или слушает в Katsodi, и могут прийти в ту же комнату.

## Пользователи и роли
Любой пользователь приложения для Windows, у которого на этом же компьютере запущен Discord. Вход в Katsodi не нужен.

## Пользовательские сценарии
- Играет музыка из плеера приложения → «Слушает»: название трека, исполнители, обложка (если это https), время.
- Человек в комнате, музыка не играет → «Смотрит»: публичная комната показывает своё название, а второй строкой — «Проводит время с n друзьями» (остальные участники комнаты) и описание комнаты (без описания — фандом или сайт источника). Приватная — «Приватная комната» и только число друзей.
- Ни того ни другого → статус очищается.

## Правила поведения
- Включено по умолчанию; выключается в настройках («Показывать активность в Discord»). При выключении статус очищается, а соединение с Discord закрывается.
- Музыка важнее комнаты. У приватной комнаты не отправляются ни название, ни фандом, ни источник.
- Обновления не чаще одного раза в 4 с (лимит Discord — 5 за 20 с), со сглаживанием 1,5 с; одинаковое состояние повторно не отправляется.

## Интерфейс и состояния
Карточка «Discord» в настройках: переключатель и строка с фактическим состоянием: в сборке нет приложения Discord / выключено / подключено / ждём Discord.

## Техническая реализация
- `src/presentation/DiscordPresence.{h,cpp}`: локальный IPC Discord (именованный канал `discord-ipc-0…9` через `QLocalSocket`), рукопожатие (`op 0`, `v: 1`, `client_id`), `SET_ACTIVITY` (`op 1`) с `pid` приложения; ответ на ping. Повторная попытка подключения раз в 20 с, если Discord запустят позже.
- Тип активности: 2 (Listening) для музыки, 3 (Watching) для комнаты.
- Картинки (2026-11-20) — https-адреса, которые Discord загружает сам: большая — обложка трека, арт фандома комнаты с сайта (`https://katsodi.watch/images/fandoms/…`) или, без фандома и у приватной комнаты, `public/images/discord/room-cover.png` (рисует `node scripts/render-room-cover.mjs`); без обложки — значок сайта `icons/icon-512.png`. Маленький круг — аватар самого человека в Discord (из ответа READY, CDN Discord): аватары Katsodi закрыты (их видят только соседи по комнате), поэтому Discord их загрузить не может.
- Кнопки (не больше двух): «Открыть комнату» (страница комнаты на сайте; у приватной нет) или «Слушать в Spotify/YouTube/SoundCloud» для трека, и «Открыть Katsodi». Discord не показывает кнопки самому владельцу статуса — их видят другие. Проверено 2026-11-20: в ответе на SET_ACTIVITY Discord возвращает обе кнопки.
- Id приложения Discord — `1573116517133058139` (приложение Katsodi; id публичный, его передаёт каждый клиент), значение по умолчанию в `CMakeLists.txt`. Переменная окружения `KATSODI_DISCORD_CLIENT_ID` заменяет его при сборке и, в разработке, при запуске; не цифры — функция выключена, и настройки так и пишут.
- Чистая функция `DiscordPresence::activity()` и кадрирование `frame()` покрыты `tst_core discordActivity`.

## Данные и доступы
Discord получает только описанное выше: без токенов, id пользователя и ссылок на комнаты. Сеть не используется — только локальный канал к клиенту Discord.

## Безопасность и приватность
Приватная комната не раскрывается (проверено в тесте). Настройка хранится локально (`QSettings`).

## Критерии приёмки
- Проверка канала (2026-11-20): запущенный Discord принимает рукопожатие в этом формате и отвечает `Invalid Client ID` (4000) на тестовый id — формат кадров верный.
- С id Katsodi (2026-11-20): Discord отвечает READY; приложение пишет в настройках «Подключено к Discord», активность во время музыки отправлена без отказа (отказы пишутся в журнал как `Discord activity refused`). Как статус выглядит в профиле, проверяет человек в Discord.

## Ограничения и следующие шаги
Обложка комнаты без фандома появится в Discord после публикации сайта с `public/images/discord/room-cover.png`; до этого на её месте пустая картинка. Вторая кнопка ведёт на обзор проекта `https://katsodi.watch/overview`.

# Очередь комнаты

> Русский · [[docs/en/Features/Room Queue|English]]

## Зачем нужна
Общий список «что дальше», чтобы вечер перетекал от одного видео или трека к следующему, и никому не приходилось искать ссылки. Работает вместе с [[docs/Features/Shared Playback]].

## Пользователи и роли
Добавлять ссылки может любой активный участник (общий список). Убрать ссылку может тот, кто её добавил, или владелец/модераторы. Включать элементы могут только владелец и модераторы.

## Пользовательские сценарии
Открыть вкладку «Очередь» в боковой панели комнаты, вставить ссылку и нажать «Добавить». Ведущий нажимает «Включить следующее» (или «Включить сейчас» у конкретного элемента): ссылка становится источником комнаты для всех. Когда синхронизируемое видео YouTube, Vimeo или SoundCloud заканчивается у ведущего, следующая ссылка включается сама.

## Правила поведения
- Порядок — кто раньше добавил (created_at, id). Не больше 50 ссылок на комнату; одно добавление на человека раз в 2 секунды.
- Включение идёт через set_room_source — те же правила URL, проверка владельца/модератора и ограничение раз в 2 секунды, — затем элемент удаляется, всё в одной транзакции. Новый источник сбрасывает общий таймлайн, поэтому новое видео начинается с остановленного состояния.
- Автопереход работает только у ведущего, только при непустой очереди и не чаще раза в 5 секунд.
- Изменения очереди отправляют пустой сигнал Realtime, если применена миграция 1000.

## Интерфейс и состояния
Четвёртая вкладка «Очередь» со счётчиком; появляется только при применённой миграции и открытой комнате. Форма добавления, «Дальше в комнате · N», «Включить следующее» для ведущих, строки с названием сервиса и короткой ссылкой, кнопки «Включить сейчас» / «Убрать» по правам, пустое состояние и подсказка (автопереход для ведущих, «ведущий включает ссылки» для участников). Ошибки: неверная ссылка, слишком часто, очередь заполнена. RU/EN. В боковой панели 380px вкладки показывают только текст и счётчики.

## Техническая реализация
`src/components/room-queue.tsx`; действия `addToQueue`, `removeFromQueue`, `playFromQueue` в `src/lib/server/room-actions.ts`; обновление комнаты содержит `queue` (`src/lib/server/network-data.ts`). Автопереход: `SyncedPlayer` → `onEnded` → `playFromQueue`. Vimeo и Dailymotion добавлены в реестр названий сервисов для подписей (возможности не изменились).

## Данные и доступы
Миграция `20261104001100_room_queue.sql` (после room_player 0500): таблица `room_queue` (id, room_id, url, added_by, created_at) с чтением по RLS для активных участников и без прямой записи; RPC `add_room_queue`, `remove_room_queue`, `play_room_queue`. В облаке пока не применена — [[docs/Backend Setup]].

## Безопасность и приватность
Личность и роль определяются только сессией в SQL. Ссылки — только HTTPS без пробелов, до 2048 символов; клиент дополнительно проверяет их инспектором источников. Очередь видна только активным участникам, ссылки открываются снаружи с noopener/noreferrer.

## Критерии приёмки
PGlite: порядок, добавление участником и запрет для посторонних, неверные ссылки, ограничение частоты, предел 50, включение только ведущим со сменой источника и сбросом таймлайна, общее ограничение частоты, пустая очередь, удаление только автором или ведущим. Браузер: добавление и сброс формы, «Включить следующее» у ведущего, участник убирает только свои ссылки, автопереход после окончания видео у ведущего; desktop и mobile.

## Ограничения и следующие шаги
Пока нет перетаскивания и названий у каждого элемента: строки показывают сервис и ссылку, а подробности текущего элемента — в полосе «Сейчас играет». Два настоящих аккаунта с облачным проектом не проверялись.

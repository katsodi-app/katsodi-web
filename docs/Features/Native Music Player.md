# Музыкальный плеер приложения

> Русский · [[docs/en/Features/Native Music Player|English]]

## Зачем нужна
Слушать подборки Katsodi прямо в [[docs/Features/Native Desktop Client]], без комнаты: подборки выглядят как плейлисты, свой плеер с очередью, полоска внизу и полноэкранный вид.

## Пользователи и роли
Все, включая гостей: подборки публичные, плеер работает только на этом компьютере. «Слушать в комнате» требует входа, как на сайте.

## Пользовательские сценарии
- Выбрать подборку: «Топ за всё время», «Spotify: неделя», «YouTube: топ за всё время» (150 музыкальных видео по общему числу просмотров), «Популярное», «В тренде».
- «Слушать всё», «Перемешать», поиск в подборке, «В очередь» (вся подборка в конец очереди), сортировка: порядок чарта → по названию → по артисту.
- Щелчок по треку играет подборку с него; меню «⋮»: «Играть следующим», «В очередь», «Слушать в комнате», «Открыть у провайдера».
- Полоска внизу: трек, назад / играть / вперёд, время, перемешивание, повтор (нет → очередь → трек), громкость, полный вид, стоп.
- Полный вид: обложка на размытом фоне, перемотка, управление, громкость, «Дальше».

## Правила поведения
- YouTube и SoundCloud играют целиком; Spotify через свой встроенный плеер играет отрывок (около 30 с), громкость Spotify не меняет — приложение пишет об этом. Apple Music и TikTok в приложении не играют: строки неактивны, есть подсказка.
- Трек, не готовый за 25 с, отмечается ошибкой и пропускается.
- Очередь живёт до закрытия приложения; помощник плеера останавливается через минуту паузы.

## Интерфейс и состояния
Сверка с образцом (плейлист Liner и его плеер), элемент за элементом:

| Элемент | Образец | Было | Стало |
|---|---|---|---|
| Фон | нейтральный тёмный, мягкое свечение обложки | зелёный фон темы | размытая затемнённая обложка за шапкой, плавно уходит вниз (маска, без края) |
| Обложка | ~250 px, скругление 12, только арт | 330 px с названием поверх | 240 px, скругление 14, только арт, источник 640 px |
| Заголовок | гротеск, жирный, ~44 px | узкий Oswald 64 px | Manrope ExtraBold 44 px |
| Артисты | 24 px, приглушённые | 17 px | 21 px |
| Плашка | «8 tracks · 26 min 38 sec» | плюс дата обновления в плашке | число и длина; дата — тихим текстом рядом |
| Кнопки | светлая «Play all» и квадратная «перемешать», скругление ~8 | белая «таблетка», круглая кнопка | прямоугольники со скруглением 10 |
| Справа | поиск, «Add to queue», сортировка | поиск слева | поиск, «В очередь», сортировка справа |
| Список | в одной светлой панели | строки без панели | панель со скруглением 18, без швов |
| Строки | обложка 72, название обычное, «⋮» без круга | 52, жирное, «⋮» в круге | 64 (источник 192 px), Medium 18 px, «⋮» плоская |
| Длительность | у каждого трека | только у SoundCloud | так же: у чартов Spotify и YouTube длительности в данных нет |
| Полоска | белый круг «играть», плоские «назад/вперёд», группа справа | зелёная кнопка, кнопки в кругах | белый круг, плоские кнопки, группа в рамке |
| Прогресс | заливка фона полоски слева направо | тонкая линия сверху | заливка фона с чёткой кромкой; нажатие или перетаскивание по полоске перематывает, при наведении видны место и время (2026-11-20) |
| Полный вид | обложка, текст песни справа | — | обложка и «Дальше» справа: текстов песен в Katsodi нет |

Качество обложек: Spotify 640 px вместо 300, SoundCloud 500 px вместо 100, YouTube 1280 px там, где у видео есть такой кадр (140 из 150), иначе 480 px (у таких видео видны чёрные полосы).

## Техническая реализация
- `MusicPlayerController` (`Tune` в QML): очередь, перемешивание, повтор, перемотка, громкость поверх `katsodi-player --mode music` — тот же помощник, окно за видимой частью окна приложения, флаги против приостановки фоновых окон.
- Страница плеера `/api/native/v1/player` получила Spotify (официальный iFrame API): скрипт с `embed-cdn.spotifycdn.com` и `'unsafe-eval'`, разрешённые только на этой странице без данных Katsodi.
- Данные: YouTube — `kworb.net/youtube/topvideos.html` (`parseKworbTopVideos`); при обновлении `enrichCovers` берёт кадр YouTube `maxresdefault` и обложки Spotify через публичный oEmbed; `sharpMusicCover` увеличивает обложки в общем представлении для сайта и приложения. Свежий файл данных используется, пока в базе нет более нового снимка.

## Данные и доступы
Плеер ничего не хранит. Обновление чартов (`npm run music:refresh`) читает публичные страницы kworb и oEmbed Spotify без ключей.

## Безопасность и приватность
Плеер провайдера — отдельный процесс с временным профилем; страница плеера не содержит данных аккаунта.

## Критерии приёмки
Проверено 2026-11-18:
- `tst_player_live musicMode`: в режиме музыки за видимой областью YouTube готов за 2,1 с и играет, SoundCloud — 3,1 с, Spotify — 2,0 с (отрывок 29,7 с).
- Модульные тесты: страница плеера разбирается без ошибок (сломанный скрипт и был причиной «Загрузки» без конца), разбор топа YouTube, увеличение обложек, обложки при обновлении; `musicPlayerQueueRules` в Qt.
- Снимки окна приложения: подборки Spotify и YouTube, полоска с играющим треком, полный вид.

## Ограничения и следующие шаги
Нет текстов песен и длительностей для чартов Spotify/YouTube; очередь не сохраняется; Spotify — только отрывки. Сайт в production не разрешает скрипты Spotify (`embed-cdn.spotifycdn.com`, eval) — встроенный плеер Spotify на сайте стоит проверить отдельно.

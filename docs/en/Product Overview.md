# Product Overview

> English · [[docs/Product Overview|Russian original]]

Katsodi provides rooms for watching and listening together to content users can access. Russian and English are equally supported UI languages. The first version lets people explore without an account; example rooms are labeled Demo, and user-created rooms are labeled Local.

The MVP requires real server accounts, privacy and realtime capabilities. They are not implemented in the current version. There are no paid features, advertisements, DRM bypasses or unlicensed covers.

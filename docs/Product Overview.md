# Продукт

> Русский · [[docs/en/Product Overview|English]]

Katsodi — комнаты для совместного просмотра и прослушивания доступного пользователям контента. Русский и английский — равноправные языки интерфейса. Первая версия позволяет исследовать интерфейс без аккаунта; примерные комнаты помечены Демо, созданные пользователем — Локально.

MVP требует настоящих серверных аккаунтов, приватности и realtime. В текущей версии они не реализованы. Нет платных функций, рекламы, обхода DRM или нелицензированных обложек.

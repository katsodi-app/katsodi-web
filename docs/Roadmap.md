**Принять на настоящей установке** ([[docs/Acceptance Checklist]]):
- [ ] Профили, друзья, опыт: загрузка аватара и обложки, заявки и блокировки, ежедневный опыт и достижения.
- [ ] Картинки чата в Storage, переподключение голоса и удаление из звонка, ручные проверки клавиатуры и экранного диктора.

**Перед публичным запуском:**
- [ ] Хостинг с HTTPS-доменом (заодно заработают встраивания VK; локально им нужен `npm run dev:https`, который не запустился у владельца).
- [ ] Production-планировщик для обработчика голоса каждые 30 с (многие cron хостингов разрешают только раз в минуту).
- [ ] Свой SMTP для писем (встроенная отправка Supabase сильно ограничена), шаблон письма с token-hash.
- [ ] Заменить ключи, которые были отправлены в чат: секрет LiveKit, секретный ключ Supabase, ключи VK.
- [ ] Мониторинг (`SENTRY_DSN`), резервные копии, staging.
- [ ] Отправить локальные коммиты в удалённый Git.

**Функции и доработка:**
- [ ] Комната следует за вкладкой сцены ведущего; неудачная ссылка плеера предлагает «Открыть как сайт».
- [ ] Ключ Hyperbeam для общего браузера, если нужен.
- [ ] Журнал модерации, экспорт и удаление аккаунта.
- [ ] Удалить старые слои CSS, которые перекрываются новыми стилями.
- [ ] Показ демо с телефона требует нативного приложения: мобильные браузеры не умеют показывать экран.

Все визуальные маршруты и их ограничения перечислены в [[docs/Page Catalogue]]. Новые /friends и /moderation являются оформлением будущих сервисов, не готовым backend. Без Supabase auth-формы и общие комнаты показывают явную недоступность. Неизвестные маршруты возвращают 404.

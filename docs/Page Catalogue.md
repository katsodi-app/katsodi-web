# Карта экранов Katsodi

> Русский · [[docs/en/Page Catalogue|English]]

Все перечисленные UI используют [[docs/Features/Brand Pages]]. API и auth callback — транспортные маршруты, они не являются самостоятельными визуальными страницами. Ниже различаются оформление и работоспособность сервисов.

| Адрес / состояние | Композиция | Реальные возможности / ограничения |
| --- | --- | --- |
| / | Брендовый hero, коллаж постеров, три маршрута первого шага | CTA регистрации и исследования |
| /home | Редакционный hero, подборки, навигационные карточки | Существующие подборки, поиск ссылок и локальные данные |
| /rooms | Орбитальный intro, поиск/формат, карточки | Черновики и помеченные примеры |
| /rooms/create | Форма + атмосферная карточка | Создание локального черновика |
| /room/[roomId], локальная | Новый RoomStage и отдельная панель ограничений | Локальный draft, чата нет; ссылка на общие комнаты |
| /network | Intro, фильтры, карточки или пустое состояние | Каталог под действующим RLS |
| /network/create | Форма + живой предпросмотр | Только подтверждённый аккаунт, иначе вход |
| /room/[roomId], серверная | RoomStage, сообщения, composer, участники | Существующий polling; медиа ждут миграцию |
| /saved | Intro коллекции, фильтры или пустое место | Локальные закладки |
| /fandoms | Intro, поиск/категории, равные постеры | 150 фандомов, локальный выбор |
| /fandoms/[slug] | Крупный постер, действие выбора, похожие миры | Известный ID, persist выбора; unknown — 404 |
| /friends | Две панели, разделы друзей/заявок/блокировок | Дизайн готов, сервис не подключён, поиск disabled |
| /profile/[username] | Паспорт + bio либо безопасное empty | Только доступные по RLS поля; отсутствие и отказ выглядят одинаково |
| /account | Паспорт сбоку, секции имени/интересов, сохранение | Только свои данные; guest/error/unconfigured отдельны |
| /onboarding | Intro, якоря трёх секций, тот же профиль | Существующая атомарная запись; без принудительного wizard |
| /settings | Индекс разделов, темы, язык, локальные данные, профиль | Только действующие настройки |
| /join | Приглашение в отдельной карточке | Нет токена / нужен вход / принятие / ошибка |
| /invite/[token] | Безопасный redirect к /join#TOKEN | Совместимый alias; fragment-ссылка предпочтительна |
| /moderation | Брендовый shield, разделы будущего рабочего места | Никаких приватных очередей или выданных глобальных ролей |
| /credits | Редакционный intro, источники изображений | Действующие внешние ссылки и лицензии |
| /login, /signup | Отдельный split-layout без навигационного шума | Существующие Server Actions и disabled без config |
| /forgot-password, /reset-password, /verify-email | Единый auth flow | Ошибки, pending, инструкция почты, resend |
| 404 | Орбитальный intro и карточка возврата | Настоящий HTTP 404 для неизвестной страницы |
| error.tsx | Брендовая пауза с retry и возвратом | Реальный reset error boundary |
| loading.tsx | Адаптивный скелетон | aria-busy/status, reduced motion |

Снимки сохраняются в `.local/brand-pages` и не коммитятся. Подтверждённые формы, read-only профиль, error и loading визуально проверяются на изолированном стенде с настоящими компонентами; авторизация продуктовых маршрутов не ослабляется.

# Серверная основа Katsodi

> Русский · [[supabase/README.en|English]]

Облачный проект подключён. Проверка 2026-11-08 подтверждает возможности музыкальных комнат (миграция 22), но хранилища чартов (миграция 23) ещё нет. Применение оставшейся миграции и проверка описаны в [[docs/Features/Music Activation]]. Приложение использует серверные ключи издателя/worker; публичные клиенты — publishable или anon.

Для новой пустой базы файлы `migrations/` применяются по времени. Первые два:

1. `migrations/20261101000100_foundation.sql` — таблицы, RLS, функции с проверкой подтверждённого пользователя, атомарные операции комнат и приглашений.
2. `migrations/20261101000200_fandom_seed.sql` — 150 фандомов с теми же IDs, что в локальном каталоге.

Миграции проверяются на PGlite. Для существующего облачного проекта сначала сверяйте схему и историю миграций; не запускайте повторно файлы основы. Живая приёмка отслеживается отдельно от тестовых стендов.

Порядок настройки, шаблоны писем и ручные сценарии: [[docs/Backend Setup]]. Архитектура: [[docs/Architecture]], права: [[docs/Features/Server Authorization]], результаты: [[docs/Verification]].
